# Android 手机版《杀戮尖塔》

## 目标

在 Android 版《杀戮尖塔》中可靠地识别当前界面、做出符合用户目标的决策，并逐步执行操作。

本技能针对初代《杀戮尖塔》移动版，Android 包名为 `com.humble.SlayTheSpire`。不要把《杀戮尖塔 2》、模组或其他卡牌游戏的规则和图标套用进来。

## 事实优先级

按以下顺序判断画面和规则：

1. 当前截图中清晰可见的文字、数字和高亮状态。
2. 游戏当前页面自带的图例、卡牌说明、遗物说明、状态提示和选项文本。
3. 本技能中的参考规则。
4. 经验性推断。

若截图与本技能不一致，以游戏当前画面为准。不要仅凭一个模糊轮廓断言节点、意图、卡牌或按钮的含义；关键文字或数字看不清时，先重新观察，仍无法确认就停止并向用户说明。

## 会话与工具流程

1. 用 `device_list_apps` 确认游戏是否可用。
2. 用 `device_open` 建立设备会话。用户没有要求后台执行时，优先使用 `main` 模式。
3. 若游戏未在前台，用 `device_action` 的 `open_app` 打开 `com.humble.SlayTheSpire`。
4. 用 `device_observe` 获取当前截图与一次性 observation id。
5. 每次只执行一个有意义的动作，然后重新观察并验证结果。
6. 完成或停止时，用 `device_close` 关闭设备控制会话；不要擅自强制结束游戏进程。

这是 Unity 游戏，结构化节点树可能很少或为空。以截图为主要依据，但不要因此跳过动作后的视觉复核。

### 动作原则

- 优先使用 `device_action` 完成单击、返回、打开应用等原子动作。
- 只有拖牌、滑动地图或确实需要连续轨迹时才使用 `device_gesture`。
- 战斗、地图选点、奖励、事件和商店都不要用 `device_batch` 连点；中间状态会改变，必须逐步观察。
- 坐标必须来自当前截图，不复用上一页或上一轮的旧坐标。
- 页面仍在动画、转场或数字结算时先等待稳定，再判断下一步。

## 权限与风险边界

- 用户只要求“看看”“分析”“给建议”时，只观察，不点击。
- 未经明确授权，不放弃现有对局、不覆盖存档、不开始会取代当前进度的新局。
- 不购买付费内容，不处理系统权限或账号弹窗。
- 遇到删牌、钥匙与遗物二选一、消耗大量金币、可能致死的事件选项等不可轻易撤销的选择时，先完整读清收益与代价。
- 若用户已经授权“代玩/继续打”，可自主完成普通战斗和常规路线操作；遇到会明显改变整局方向且用户没有给出偏好的选择，再简短询问。

## 先识别页面类型

每次观察后，先归类为以下一种，再按对应流程处理：

- 标题页、存档页或主菜单
- 角色选择、进阶等级或开局设置
- 涅奥奖励
- 地图
- 战斗
- 卡牌奖励、遗物奖励或药水奖励
- 未知事件
- 商店
- 休息处
- 宝箱
- Boss 奖励
- 胜利、死亡或统计结算
- 系统弹窗、同步提示或异常页面

不要因为看见卡牌就立即按战斗处理；奖励页、牌组查看和商店也会展示卡牌。

## 地图识别：以游戏内图例为准

地图共有七类位置：普通敌人、精英、休息处、未知、宝箱、商人和 Boss。

### 正确识别节点

- **未知**：问号 `?`。可能进入事件，也可能变成战斗、商店或宝箱；不能当成“必定是事件”。
- **商人**：地图图例中的 `$` 商人符号。
- **宝箱**：宝箱图案。
- **休息处**：篝火图案。
- **普通敌人**：地图图例中的普通敌人面孔/怪物符号。
- **精英**：比普通敌人更醒目、带角的精英面孔符号。
- **Boss**：地图顶部的固定 Boss 节点/徽记；不要把普通路线节点误认成 Boss。

不要把普通敌人笼统写成“小怪图标”，也不要只凭“像骷髅”就判断精英。地图右侧图例是当前版本最可靠的对照物；若移动版允许，点按图例中的类别可高亮或放大地图上同类节点，用它消除歧义。

带火焰效果的精英是强化精英，与翡翠钥匙相关；它不是一种普通地图节点，也不能按普通精英风险估算。

### 判断可达路线

1. 找到当前所在节点或地图底部的起点。
2. 沿实际连接线向上追踪，只比较当前确实可达的节点。
3. 不以“离当前位置最近”或“看起来在正上方”为可达依据。
4. 若需要滑动地图，滑动后重新定位当前节点、连线和目标节点。
5. 点击节点后重新观察，确认已进入预期页面；不要假设一定还会出现二次确认。

### 路线决策

结合当前生命、牌组强度、药水、金币、遗物、即将面对的 Boss 以及后续连线路线评估，而不是只看下一个节点：

- 血量健康且输出/防御成型时，可考虑精英以获取遗物。
- 血量危险、牌组尚弱或缺少药水时，降低精英密度并保留休息处。
- 金币足够且牌组需要删牌或关键补强时，提高商店价值。
- 未知节点有波动，不把它无条件视为安全路线。
- 比较一整段路径中的精英、休息处、商店和强制战斗数量。

## 战斗界面与敌人意图

敌人意图显示在敌人头顶。先识别意图，再算伤害和出牌顺序。

### 意图参考

- **攻击**：剑形攻击意图，并显示预计伤害数字；多段攻击通常显示“单段伤害 × 次数”。
- **防御**：盾牌意图。
- **强化**：游戏的 Buff 意图符号，常呈蓝色火焰/光团式图形。不要把它描述成“上箭头”。
- **削弱**：游戏的 Debuff 意图符号。不要把它描述成“下箭头”。
- **复合意图**：攻击并削弱、攻击并强化、攻击并防御等会同时包含攻击和第二种效果的信息，不能只读取伤害数字。
- **未知**：问号意图，表示具体行动无法确定。
- **睡眠**：`Z`/睡眠符号。
- **眩晕**：星形眩晕符号。
- **逃跑**：逃离意图。

有些敌人会使用不直接造成伤害的特殊行动。若玩家拥有符文圆顶，敌人意图会被隐藏；此时“没有看到图标”不等于敌人本回合不行动。

图标模糊时，优先依据头顶伤害数字、复合标记、状态文本和当前敌人行为规律综合判断，但不要把不确定推断报告成事实。

### 每回合读取清单

执行任何牌前，至少确认：

- 玩家当前/最大生命、格挡和能量。
- 每名敌人的当前生命、格挡、意图与关键状态。
- 手牌中每张候选牌的费用、伤害、格挡、目标和附加效果。
- 玩家身上的力量、敏捷、易伤、虚弱、脆弱等关键状态。
- 相关遗物与药水，特别是会改变费用、抽牌、伤害或回合结算的效果。

如果卡牌文字没有读清，不要仅根据卡图或颜色猜牌。

### 出牌计算

1. 先判断能否本回合击杀威胁最大的敌人。
2. 不能击杀时，计算预计承伤：敌方攻击、力量、易伤、虚弱、多段攻击与玩家格挡都要纳入。
3. 检查能量和牌序，避免先打出会关闭后续路线的牌。
4. 再考虑抽牌、加费、易伤/虚弱、力量、姿态、球、药水等顺序收益。
5. 若没有更高价值动作，再结束回合。

不要只追求“把能量花完”。保命、斩杀、保留关键牌或避免触发敌人机制可能更重要。

### 移动端出牌

- 有目标的牌：优先点选卡牌，确认牌被抬起/高亮，再点目标敌人；若当前版本或状态不响应，再采用从卡牌拖到目标的方式。
- 无目标的牌：将卡牌拖向上方的中性出牌区域，确认释放后再松手。
- 取消选牌：可点回已选卡牌，或在空白侧边向下滑动；取消后要确认手牌已恢复正常状态。
- 多名敌人时，必须在截图中重新确认目标位置，不能沿用上一只敌人的坐标。
- 每打出一张关键牌后重新观察，核对能量、手牌、敌人生命、格挡和状态变化。

如果误选了一张牌，先取消选择，不要用试探性点击敌人的方式“看看会不会出牌”。

## 奖励与非战斗页面

### 卡牌奖励

1. 读清所有候选牌的名称、升级状态、费用和效果。
2. 结合当前牌组、遗物、能量结构和当前 Act 判断即时价值。
3. “跳过”是正常选项；不要为了拿牌而拿牌，也不要机械追求固定牌组张数。
4. 点击后重新观察，确认奖励页已退出或还有遗物/药水等奖励未领取。

### 遗物与药水

- 阅读遗物说明，检查它是否改变路线、战斗计算或后续选牌。
- 药水槽已满时，先比较现有药水和新药水；丢弃是不可逆动作。
- 不要因为奖励图标发光就默认已经领取。

### 商店

- 先读取金币，再查看卡牌、遗物、药水和删牌服务的实际价格。
- 比较购买与删牌的机会成本，保留可能需要的后续金币。
- 被售罄标记、无法负担或点击区域不清楚时不要试点。
- 完成购买后重新读取金币与商品状态。

### 休息处

- 基础选项是休息和锻造；遗物或角色机制可能增加其他选项。
- 普通休息默认回复最大生命的 30%（向下取整），遗物等效果可能改变收益。
- 决策时同时考虑当前血量、下一段路线、Boss/精英压力和关键升级收益。
- 不要只按固定血量阈值机械选择休息或锻造。

### 未知事件

- 逐项读取选项的即时收益、生命/金币/卡牌代价和离开选项。
- 百分比伤害、最大生命损失、诅咒和金币变化不能凭经验估算。
- 事件规则可能随角色、遗物、进阶等级和当前状态改变，以屏幕文本为准。

### 宝箱与钥匙

- 打开宝箱后确认获得内容和后续选择。
- 在已解锁通往终幕的条件下，蓝宝石钥匙可能与宝箱遗物形成二选一；强化精英对应翡翠钥匙，休息处可出现红宝石钥匙。
- 选择钥匙会放弃眼前资源或机会，除非用户已明确要进终幕，否则先结合整局目标判断。

### Boss 奖励

- Boss 遗物会显著改变能量、抽牌、费用、回复或路线策略。
- 完整读取所有候选遗物的收益与代价后再选择；不要只因为“加能量”就忽略副作用。

## 角色相关检查

识别角色后，关注其核心资源，但不要强行套预设流派：

- **铁甲战士**：力量、消耗、生命与格挡资源。
- **静默猎手**：毒、弃牌、小刀、抽牌与敏捷。
- **故障机器人**：球槽、集中、不同球与能量循环。
- **观者**：姿态、退出姿态、神格、保留与致死风险。

选牌首先解决当前牌组的伤害、防御、过牌和能量问题。协同价值必须建立在已经拥有或可靠获得的组件上，不能为了想象中的成型流派牺牲眼前生存。

## 异常恢复

- 点击无响应：重新观察，确认是否仍在动画、弹窗遮挡、坐标偏移或页面已变化。
- 进入非预期页面：先观察并识别，不连续按返回。
- 牌被选中但未打出：确认目标要求并安全取消，再重新操作。
- 地图识别不清：打开/使用地图图例高亮，必要时小幅滑动后重新定位连线。
- 加载时间较长：等待页面稳定；不要重复点击可能触发两次的按钮。
- 出现系统权限、登录、云同步冲突或存档选择：停止并请用户决定。

## 完成汇报

结束时简要说明：

- 做到了哪个节点、回合或结算页面。
- 关键选择及理由。
- 当前生命、路线、牌组或资源中需要用户关注的风险。
- 因信息不清或需要授权而停止时，明确指出尚未执行的动作。

不要声称“已选择”“已领取”或“已击杀”，除非动作后的截图已经验证结果。
