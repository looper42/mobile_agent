# 《杀戮尖塔》获胜策略

本 Skill 只决定“应该做什么”，不规定怎样触摸游戏界面。

实际操作 Android 版游戏时，应同时使用安卓操作 Skill，由操作 Skill 负责将本 Skill 的决策转化为点击、拖拽和确认动作。

# 默认目标

用户没有指定特殊目标时：

- 以稳定通关为首要目标；
- 优先继续已有对局；
- 不强行追求特定流派；
- 不为了炫技、无限循环或极端组合降低胜率；
- 不使用回档、强制退出或修改存档；
- 独立完成普通决策，不为每次出牌询问用户。

用户指定角色、进阶、成就、构筑或特殊结局时，在不违背该目标的前提下最大化胜率。

# 决策依据

只根据当前游戏画面中的实际信息决策，包括：

- 角色、章节、楼层和进阶等级；
- 当前生命和最大生命；
- 金币、药水和遗物；
- 当前牌组和升级情况；
- 地图与可选路线；
- 当前敌人、意图和状态；
- 游戏版本实际显示的卡牌与遗物文字。

不确定卡牌、遗物、事件或敌人机制时，先读取游戏内详情，不凭模糊记忆做不可逆选择。

# 战斗决策

## 每回合读取状态

回合开始后确认：

- 当前生命；
- 当前能量；
- 当前格挡；
- 全部手牌及费用；
- 抽牌堆、弃牌堆和消耗牌堆的重要内容；
- 每个敌人的生命、格挡、状态和行动意图；
- 角色的力量、敏捷、虚弱、易伤、无实体等状态；
- 可用药水；
- 遗物的本回合触发状态。

## 第一优先：检查斩杀

先判断能否：

- 击杀全部敌人；
- 击杀正在攻击的敌人；
- 击杀会召唤、逃跑、强化或施加严重负面状态的敌人。

计算实际伤害时考虑：

- 力量；
- 虚弱；
- 易伤；
- 多段攻击；
- 敌人格挡；
- 无实体；
- 荆棘和反伤；
- 攻击后触发效果；
- 姿态伤害倍率。

能够安全完成斩杀时，不要浪费能量打出无意义的防御或成长牌。

## 第二优先：计算来袭伤害

不能斩杀时，计算全部敌人的总伤害。

多段攻击应计算总次数，不只读取单次伤害数字。

比较：

- 完全格挡所需资源；
- 部分格挡后的生命损失；
- 本回合输出能否减少未来伤害；
- 当前生命是否允许承受伤害；
- 是否需要药水防止大量损失。

## 第三优先：确定本回合目标

通常按以下顺序决策：

1. 安全且确定的斩杀；
2. 消灭最高威胁敌人；
3. 避免大量生命损失；
4. 建立长期能力或扩展；
5. 输出伤害；
6. 获取其他边际收益。

面对成长很快、会召唤、会逃跑或会施加严重状态的敌人时，提高输出优先级。

## 出牌顺序

主动寻找顺序收益：

- 先施加易伤，再打高伤害攻击；
- 先施加虚弱，再确定防御需求；
- 先增加力量、敏捷或集中；
- 先获得能量或降低费用；
- 先抽牌、检索或改变手牌；
- 先用低价值效果移除人工制品；
- 再施加关键减益；
- 先建立能力，再打出受能力强化的牌；
- 终结技或高伤害牌放在铺垫完成后；
- 使用依赖攻击次数、已出牌数、弃牌数或消耗数的牌前先完成积累。

每次抽到新牌、改变费用、击杀敌人或触发阶段变化后重新规划。

## 结束回合检查

结束回合前确认：

- 是否仍有可用能量；
- 是否有零费牌；
- 是否还有可实现的斩杀；
- 是否有必要的防御；
- 是否需要使用药水；
- 是否会在危险姿态下结束回合；
- 是否遗漏遗物、保留牌或回合结束效果。

# 生命管理

生命是跨房间资源，不必追求每回合零伤，但应避免没有战略收益的伤害。

可以承受伤害的情况：

- 能换取确定斩杀；
- 能显著减少未来回合伤害；
- 能建立决定性能力；
- 角色或遗物可以可靠恢复；
- 保留关键资源能提高后续生存率。

不应承受伤害的情况：

- 有足够资源可以防御；
- 只是为了增加少量无意义输出；
- 会使下一场精英或首领进入高死亡风险；
- 为节省药水而面临死亡；
- 为执行不可靠组合而放弃稳定行动。

# 药水策略

药水用于跨过危险回合，不应无限保留。

主动使用药水的情况：

- 可以防止死亡；
- 可以避免大量生命损失；
- 可以击败精英；
- 可以完成关键斩杀；
- 可以安全度过首领阶段；
- 药水栏已满并且即将获得新药水。

不要：

- 在战斗结果已经确定时浪费药水；
- 为保留药水承担死亡风险；
- 使用随机药水后沿用旧计划；
- 忽略药水与卡牌、遗物之间的联动。

# 地图路线

进入章节后先评估所有可见路线。

考虑：

- 当前生命；
- 牌组战斗力；
- 药水；
- 金币；
- 精英数量；
- 篝火数量；
- 商店位置；
- 问号房间；
- 当前章节首领；
- 路线是否保留后续分支。

## 第一章节

主要目标：

- 尽快获得可靠攻击；
- 准备适量群体伤害；
- 在牌组和生命允许时击败精英；
- 为首领准备足够输出。

不要在初始牌组缺乏伤害时盲目连续挑战精英。

## 第二章节

第二章节普通战斗也可能造成大量伤害。

重点补足：

- 群体伤害；
- 稳定防御；
- 过牌；
- 能量；
- 持续成长。

牌组尚未成形或生命偏低时，不选择过度激进的精英路线。

## 第三章节

围绕最终首领提高：

- 稳定性；
- 持续成长；
- 关键回合防御；
- 牌组循环；
- 首领针对能力。

不要为低价值奖励承担可能直接导致失败的风险。

# 卡牌选择

每次奖励都先看完所有选项，并把“跳过”视为正常选择。

评估卡牌时考虑：

- 是否解决当前最严重的问题；
- 是否与现有卡牌和遗物形成可靠联动；
- 抽到时是否经常有效；
- 能量能否支持；
- 是否需要升级；
- 是否稀释关键牌；
- 是否有助于下一场精英或首领；
- 当前牌组是否已经有足够同类功能。

## 选牌阶段

### 前期

优先：

- 高效率攻击；
- 必要防御；
- 少量群体伤害；
- 能立即发挥作用的牌。

避免拿入只有完整组合后才有用的组件。

### 中期

补充：

- 过牌；
- 能量；
- 群体伤害；
- 关键减益；
- 持续成长；
- 构筑核心缺少的组件。

### 后期

优先：

- 稳定性；
- 首领对策；
- 关键回合防御；
- 扩展能力；
- 牌组循环效率。

不要因为卡牌稀有就自动选择。没有合适卡牌时跳过。

# 牌组构筑原则

- 不强行追求预设流派；
- 根据已经获得的卡牌和遗物构筑；
- 先确保单卡有用，再考虑组合上限；
- 兼顾输出、防御、过牌、能量和成长；
- 避免加入过多功能重复的普通牌；
- 牌组精简有价值，但不能拒绝真正缺少的功能；
- 无限循环只有在组件、牌组大小和稳定性都已满足时才应追求。

# 遗物选择

读取实际效果，并评估：

- 是否立即提高战斗力；
- 是否与现有牌组联动；
- 是否需要改变出牌方式；
- 是否存在负面代价；
- 是否影响回复、药水、金币、敌人意图或篝火；
- 是否会破坏现有核心策略。

## 首领遗物

额外能量通常很强，但必须具体评估代价。

比较：

- 当前牌组是否缺能量；
- 是否有足够过牌使用额外能量；
- 代价是否会破坏防御、回复、升级或选牌；
- 其他遗物是否提供更适合的成长方式。

不要只看到“每回合多一点能量”就自动选择。

# 篝火决策

## 休息

在以下情况下提高休息优先级：

- 当前生命不足以承受下一场危险战斗；
- 牌组不稳定；
- 没有合适药水；
- 下一节点是精英或首领；
- 失败风险明显高于一次升级的收益。

## 升级

在以下情况下提高升级优先级：

- 当前生命安全；
- 升级能降低关键牌费用；
- 升级能增加抽牌、能量或持续效果；
- 升级能显著提高核心攻击或防御；
- 升级能明显改善下一场关键战斗。

不要为了收益很小的升级承担明显死亡风险。

# 商店决策

进入商店后先查看全部商品，再决定购买顺序。

优先考虑：

- 解决牌组明显缺陷的遗物；
- 移除诅咒；
- 移除低价值基础牌；
- 对下一场精英或首领有效的卡牌；
- 能避免死亡的药水；
- 与现有构筑存在直接联动的商品。

避免：

- 因稀有度冲动购买；
- 先买低价值商品导致买不起核心商品；
- 买入只有理想组合中才有用的组件；
- 为保留金币而错过显著提高胜率的购买。

# 事件决策

读取全部选项和代价后比较：

- 生命损失；
- 最大生命变化；
- 金币；
- 卡牌移除、升级或变化；
- 遗物；
- 诅咒；
- 随机成功率；
- 失败后果；
- 后续路线需求。

不要只看即时奖励。可能严重污染牌组或导致死亡的选项应谨慎选择。

# 角色策略

## 铁甲战士

- 前期优先可靠伤害；
- 利用战斗后回复承受可控伤害；
- 力量、消耗、格挡和自残体系都需要实际组件；
- 不要只拿收益牌而忽略过牌和能量；
- 稳定防御之外仍需要首领战成长能力。

## 静默猎手

- 起始牌组较大，前期需要提升单卡质量；
- 尽早补充直接伤害和群体伤害；
- 毒、飞刀和弃牌可以混合；
- 弃牌体系需要同时拥有弃牌来源与弃牌收益；
- 防御能力强时仍需确保拥有持续输出。

## 故障机器人

- 每回合考虑充能球类型、顺序和球槽；
- 生成新球可能触发最右侧球的激发效果；
- 集中、球槽和球生成需要保持平衡；
- 不要只增加球槽而没有足够充能球；
- 能量与过牌应匹配。

## 观者

- 进入愤怒前必须计算斩杀和敌方伤害；
- 保留退出愤怒或进入平静的手段；
- 无法斩杀时不要在危险情况下以愤怒姿态结束回合；
- 神格和无限循环必须建立在实际牌堆与能量条件上；
- 高爆发不能替代安全计算。

# 失败前检查

角色可能死亡时，检查所有可能的存活路线：

- 药水；
- 零费牌；
- 抽牌；
- 能量生成；
- 减益；
- 姿态切换；
- 击杀部分敌人；
- 改变敌人攻击力；
- 遗物触发；
- 无实体、缓冲或复活效果。

确认没有存活路线后再接受失败，不使用回档改变结果。

# 完成与汇报

在以下节点简短汇报：

- 开始一局；
- 进入新章节；
- 构筑方向明显变化；
- 遇到必须由用户决定的问题；
- 获胜、失败或目标完成。

最终报告：

- 角色；
- 进阶等级；
- 到达楼层；
- 胜负；
- 核心卡牌；
- 核心遗物；
- 构筑方向；
- 关键胜负原因。

没有在游戏画面中确认的胜利、成就或解锁，不得声称完成。
