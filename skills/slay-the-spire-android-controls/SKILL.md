# 《杀戮尖塔》Android 操作

本 Skill 只决定“怎样正确操作游戏界面”，不决定应该选择哪张牌、攻击哪个敌人或走哪条路线。

如果同时加载了获胜策略 Skill：

- 策略 Skill 决定要执行什么动作；
- 本 Skill 将该动作转换为安卓触控操作；
- 实际操作方式以本 Skill 为准。

# 最高优先级规则

## 战斗中出牌必须拖拽

**战斗中的手牌必须按住并拖拽才能打出。不要只点击卡牌。**

禁止以下错误操作：

- 不要只单击手牌并认为卡牌已经打出；
- 不要先单击卡牌，再单击敌人；
- 不要看到卡牌被放大就认为已经出牌；
- 不要在上一张牌尚未确认生效时操作下一张牌。

### 对敌人使用的牌

攻击牌或其他需要指定敌人的牌：

1. 找到要出的手牌。
2. 按住卡牌中央。
3. 保持按住并向上拖动。
4. 出现目标箭头后，将箭头末端拖到目标敌人身体中央。
5. 确认目标敌人出现高亮或有效目标提示。
6. 在目标敌人上方松开。

### 不指定敌人的牌

防御牌、能力牌和其他不需要指定敌人的牌：

1. 按住卡牌中央。
2. 将卡牌拖向屏幕中上部的战斗区域。
3. 到达有效出牌区域后松开。

不要把不指定目标的牌拖到敌人身上，除非游戏明确要求选择目标。

### 确认卡牌已经打出

每次松开卡牌后，检查以下变化：

- 卡牌是否离开手牌；
- 能量是否减少；
- 角色是否获得格挡或状态；
- 敌人的生命、格挡或状态是否变化；
- 是否出现对应动画或图标。

如果卡牌弹回手牌，说明出牌失败。此时不要继续执行下一步，应重新检查：

- 能量是否足够；
- 卡牌是否需要目标；
- 目标是否合法；
- 拖拽终点是否正确。

调整后重新拖拽一次。连续失败时，重新读取整个界面，不要反复盲拖。

## 选择物品必须“先选中，再确定”

**在卡牌、遗物、药水、奖励或商品选择界面中，单击物品只代表选中。选中之后还必须点击“确定”。**

所有物品选择使用两步操作：

1. 单击需要选择的物品，使它进入高亮、放大、勾选或已选择状态。
2. 点击“确定”“确认”“选择”“拿取”“购买”或 `Confirm` 按钮。

**选中物品不等于已经获得物品。**

选中后不得：

- 直接离开界面；
- 点击下一件物品；
- 假定奖励已经进入牌组或物品栏；
- 在未点击确定前继续其他操作。

### 找不到确定按钮时

检查：

- 屏幕底部中央；
- 屏幕右下角；
- 奖励弹窗底部；
- 被放大物品的下方；
- 被说明框遮挡的区域。

必要时等待动画结束或轻微滚动界面。没有找到并点击确定之前，不认为选择已经完成。

### 确认选择是否完成

点击确定后，至少检查一项：

- 选择界面已经关闭；
- 游戏进入地图或下一个界面；
- 卡牌已经加入牌组；
- 遗物已经出现在遗物栏；
- 药水已经出现在药水栏；
- 金币已经扣除；
- 商品显示为已售出；
- 奖励已经从列表中消失。

如果选择界面仍然存在，应重新观察按钮状态，不要继续点击其他物品。

# 通用操作循环

每个动作都使用以下循环：

1. 观察当前画面。
2. 识别界面类型。
3. 确认目标控件或拖拽目标。
4. 只执行一个动作。
5. 等待动画或界面变化完成。
6. 检查动作是否生效。
7. 成功后再执行下一动作。

不要连续快速点击，也不要一次发送多个未验证的触控动作。

# 界面识别

操作前先判断当前属于哪种界面：

- 主菜单；
- 角色或难度选择；
- 地图；
- 战斗；
- 战斗奖励；
- 卡牌选择；
- 遗物或药水选择；
- 商店；
- 篝火；
- 事件；
- 卡牌、遗物或状态详情；
- 弹窗；
- 胜利或失败结算。

画面切换后必须重新识别，不能继续使用上一界面的坐标。

# 各界面的操作方法

## 主菜单

“继续游戏”“开始游戏”“设置”“返回”等普通按钮使用单击。

点击后等待界面切换。不要在加载过程中重复点击。

如果“开始游戏”可能覆盖当前进度，不擅自操作，应请求用户确认。

## 角色与难度选择

1. 单击角色。
2. 检查角色头像或面板是否进入选中状态。
3. 设置用户指定的进阶等级。
4. 点击“开始”或“确认”。
5. 检查是否进入开局界面。

角色被高亮不代表已经开始游戏。

## 战斗

### 查看卡牌

需要阅读卡牌时，可以使用游戏支持的单击、长按或详情功能。

查看卡牌不等于出牌。关闭详情后，应重新定位手牌再进行拖拽。

### 出牌

所有手牌都按照“按住—拖拽—松开”的方式打出。

每次只出一张，确认生效后再出下一张。

### 选择敌人

需要指定敌人时，将卡牌的目标箭头拖到敌人身体中央。

不要把箭头停在：

- 敌人旁边的空白处；
- 敌人意图图标；
- 敌人生命数字；
- 另一名敌人的边缘。

### 结束回合

结束回合按钮使用单击，不需要拖拽。

点击前应确认决策模块已经给出结束回合指令。点击后检查：

- 手牌是否被弃置或保留；
- 敌人是否开始行动；
- 是否进入下一回合。

## 战斗奖励

进入奖励界面后，逐项处理金币、卡牌、遗物和药水。

选择卡牌时：

1. 单击卡牌；
2. 检查卡牌是否高亮或放大；
3. 点击“确定”；
4. 检查卡牌奖励界面是否关闭。

选择跳过时，单击“跳过”，并在出现确认按钮时再次确认。

不能只点中卡牌而不点击确定。

## 地图

1. 先查看完整可见地图。
2. 根据决策模块指定的路线找到目标节点。
3. 单击节点中央。
4. 检查是否进入对应房间。

如果节点只被高亮但没有进入房间，寻找并点击确认按钮。

地图变化后重新定位，不复用旧节点坐标。

## 商店

购买商品：

1. 单击指定商品；
2. 检查商品是否被选中；
3. 点击“购买”或“确定”；
4. 检查金币是否扣除；
5. 检查物品是否已经获得。

移除卡牌：

1. 单击移除服务；
2. 单击要移除的卡牌；
3. 检查卡牌是否被选中；
4. 点击“确定”；
5. 检查金币与牌组变化。

不要把查看商品详情误认为购买完成。

## 篝火

单击决策模块指定的动作。

如果选择升级：

1. 单击“锻造”；
2. 等待卡牌列表打开；
3. 单击要升级的卡牌；
4. 检查卡牌是否被选中；
5. 点击“确定”；
6. 检查卡牌是否显示升级标记；
7. 检查是否回到地图。

如果选择休息，点击休息后等待回复动画结束，再检查生命值变化。

## 事件

1. 读取全部事件文字和选项。
2. 单击指定选项。
3. 如果选项只是进入选中状态，点击“确定”。
4. 等待事件结算。
5. 检查生命、金币、牌组、遗物或药水变化。

不要在事件动画或文字尚未更新时重复点击。

## 药水

操作药水前先确认药水位置和名称。

使用药水：

1. 单击药水；
2. 点击“使用”；
3. 如果需要目标，按照界面提示单击或选择目标；
4. 如果出现确认按钮，点击确认；
5. 检查药水是否消失及效果是否生效。

丢弃药水：

1. 单击药水；
2. 选择“丢弃”；
3. 点击确认；
4. 检查药水栏是否腾出位置。

不得把“使用”和“丢弃”混淆。

## 宝箱和遗物

1. 单击宝箱并等待打开。
2. 单击遗物。
3. 检查遗物是否进入选中状态。
4. 点击“拿取”或“确定”。
5. 检查遗物是否出现在顶部遗物栏。

只单击遗物图标不代表已经拿取。

## 弹窗

出现弹窗后，旧界面坐标全部暂时失效。

先读取弹窗内容，再点击弹窗中的按钮。不要继续点击弹窗后方原控件的位置。

# 画面变化后的重新观察

以下情况必须重新读取画面：

- 进入新房间；
- 新回合开始；
- 打出会抽牌或改变费用的牌；
- 敌人死亡、分裂、复活或转换阶段；
- 打开或关闭详情；
- 选择物品并点击确定；
- 购买商品；
- 出现或关闭弹窗；
- 游戏从后台恢复；
- 分辨率、方向或窗口大小发生变化。

# 防止误操作

执行以下操作前额外核对一次：

- 拖拽关键卡牌；
- 选择攻击目标；
- 点击结束回合；
- 选择卡牌、遗物或药水；
- 点击确定；
- 购买商品；
- 移除卡牌；
- 丢弃药水；
- 选择不可撤销的事件选项；
- 放弃当前游戏。

核对是为了确认目标和操作方式，不是重新进行策略分析。

# 异常处理

## 触控没有生效

重新观察画面，不要立即重复点击。

判断按钮是否仍存在、卡牌是否仍在手中或物品是否仍处于选中状态，再决定重试。

## 坐标发生偏移

停止使用旧坐标，重新定位所有控件。不要根据上一张截图猜测位置。

## 动画尚未结束

等待界面稳定后再操作。不要在动画过程中连续点击或拖拽。

## 内容无法辨认

尝试打开详情、长按、等待遮挡消失或重新查看。不可逆操作的内容仍无法辨认时，暂停并请求用户协助。

## 游戏进入后台

恢复游戏后重新识别当前界面，并确认中断前最后一个动作是否真正生效。

# 完成标准

一次操作只有在画面中出现可验证结果后才算完成。

尤其记住：

- **卡牌离开手牌并产生效果，才算出牌成功。**
- **物品选中后点击确定，并在界面中确认结果，才算选择完成。**
